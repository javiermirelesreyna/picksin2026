🔑 Modo editor

Para escoger picks desde la página. Pega tu token de GitHub: se guarda solo en este navegador y nunca se publica.

¿Cómo creo el token?
  1. Abre la página para crear el token (con tu sesión de GitHub iniciada).
  2. Token name: Picksin editor. Expiration: la que quieras (por ejemplo, 1 año).
  3. Repository access: «Only select repositories» → picksin2026.
  4. Permissions → Repository permissions → Contents: «Read and write». Nada más.
  5. Generate token, cópialo (empieza con github_pat_; GitHub solo lo muestra una vez) y pégalo aquí. Puedes guardarlo en tus notas para pegarlo en cada dispositivo.
